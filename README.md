# 🛒 Brother's Birthday Gaming PC Parts List

This is the shopping list for the real-life desktop computer we are building to replace his laggy laptop!

## ⚙️ Core Components Needed:
- [ ] **Processor (CPU):** AMD Ryzen 5 5600 (Includes a cooling fan)
- [ ] **Graphics Card (GPU):** NVIDIA RTX 3050 or AMD Radeon RX 6600 (For 60+ FPS Roblox gameplay)
- [ ] **Motherboard:** B550M Motherboard (Micro-ATX size)
- [ ] **Memory (RAM):** 16GB DDR4 RAM (Get a 2x8GB kit)
- [ ] **Storage:** 1TB NVMe M.2 SSD (For fast boot-up times)
- [ ] **Power Supply (PSU):** 550W or 650W Power Supply (80+ Bronze certified)
- [ ] **PC Case:** Any Micro-ATX PC Case with a mesh front panel (For cold airflow)

## 🛠️ Assembly Checklists:
1. Install CPU, RAM, and SSD onto the motherboard outside the case.
2. Mount the power supply box into the bottom of the case.
3. Screw the motherboard into the case and plug in the power wires.
4. Click the graphics card into the middle slot and plug its power cable in.
5. Plug the monitor HDMI cable directly into the graphics card back ports.
